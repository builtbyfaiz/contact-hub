# Contact App

A simple Java Swing contact management application.

## Features
- Add contacts
- Edit contacts
- Delete contacts
- Favorite contacts
- Custom avatars
- JSON-based storage

## Tech Stack
- Java (Swing)
- Gson (JSON handling)

## Data Storage
Contacts are stored in resources/`contacts.json`.

## Run
1. Open project in VS Code
2. Run main class
